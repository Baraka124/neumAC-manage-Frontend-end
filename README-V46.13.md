# neumDesk V46.13 — Personal Activity · Portfolio Intelligence

## Baseline
Built directly on the frozen V46.12 Clinical Units consolidation release. No backend source changes.

## Product change
Personal Activity is no longer primarily a document-preview modal. The same permission-scoped, provenance-aware snapshot now powers an interactive Portfolio Intelligence workspace first, while the existing offline HTML / Print-to-PDF brief remains a formal output.

## Views
- **Overview** — structured activity metrics, source coverage, recent recorded activity and portfolio summary.
- **Timeline** — dated duties, rotation assignments and shared research/innovation milestones.
- **Portfolio** — explicitly linked studies, innovation projects and programme coordination roles.
- **Sources** — source health, provenance and information-quality caveats.
- **Document** — the existing offline evidence brief generated from the exact same snapshot.

## Trust rules preserved
- explicit staff identifier; no name guessing;
- permission-scoped source retrieval;
- source failures remain independent;
- unavailable/restricted data never becomes zero activity;
- blank calendar dates do not establish availability;
- leave reasons, contact details and private notes stay excluded;
- undated or invalid-period portfolio records are labelled rather than fabricated onto the timeline.

## Structured output
`Activity45.build()` remains the canonical snapshot builder and now attaches a structured `summary` generated by `Activity45.summarize()`. Interactive views and the formal document consume the same model.

## DepartmentOS meaning
This is the first mature **Reporting capability / structured-output client**: one verified departmental snapshot can render as interactive UI or formal document without changing source logic.

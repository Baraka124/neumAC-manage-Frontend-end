# Phase 5.7 — Research composition

## Purpose

Phase 5.7 keeps the Phase 5.6 information architecture but improves the actual composition of the Research areas. The goal is to use the page width intentionally without reintroducing cards, decorative science graphics or campaign copy.

## Changes

- Replaced the stretched title/paragraph/link layout with a two-part editorial spread.
- Scientific narrative occupies the primary column.
- Coordination, current study activity and the route to the detail page occupy a dedicated orientation column.
- Alternating visual order creates rhythm without changing content priority.
- The title and the explicit “View research line” action both link to the detail page; the whole spread is no longer one giant link.
- Removed visible line numbering from the public composition.
- Kept focus terms as quiet supporting metadata.
- Added runtime public-copy normalisation so legacy hospital-acronym text arriving from the backend renders as `Área Sanitaria da Coruña e Cee`.
- Tightened the Research section introduction to factual programme language.

## Design principle

Use whitespace to separate ideas, not as a substitute for composition.
